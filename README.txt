VIJAA — PERSONAL PORTFOLIO

CARA MENJALANKAN
1. Extract folder vijaa-portfolio.
2. Buka index.html di browser.
3. Untuk hasil terbaik, jalankan lewat Live Server di VS Code.

GANTI FOTO PROFIL
- Siapkan foto portrait.
- Ubah nama fotonya menjadi fileimage.jpg.
- Timpa file fileimage.jpg yang ada di folder utama website.
- Refresh halaman.

TAMBAH HASIL FOTOGRAFI
- Buka bagian Photography di website.
- Klik + ADD PHOTOS.
- Pilih satu atau beberapa foto dari perangkat.
- Foto tersimpan di browser/perangkat yang dipakai. Foto tidak otomatis tersinkron ke perangkat lain.
- Tombol × di pojok foto untuk menghapus foto dari galeri browser.

EDIT PROJECT
- Buka index.html.
- Cari bagian SELECTED WORK.
- Ubah judul dan deskripsi project sesuai pengalaman asli.
- Ganti file gambar di folder assets dengan file milikmu. Pertahankan nama file project-video.svg, project-photo.svg, atau project-journalism.svg, atau sesuaikan nama file pada index.html.

GANTI EMAIL
- Buka index.html.
- Cari your-email@example.com lalu ganti dengan alamat email yang dipakai.

UBAH WARNA
- Buka styles.css.
- Ubah variabel --pink, --pink-deep, dan --pink-soft di bagian :root.

STRUKTUR FILE
index.html       Halaman website
styles.css       Tampilan dan responsive layout
script.js        Navigasi dan fitur upload galeri
fileimage.jpg    Placeholder foto profil
assets/          Logo dan gambar placeholder project
